术语含义
界面编号U-xx 表示用户端界面，A-xx 表示管理端界面，全局唯一、不再复用
区块页面内的一个视觉分区，如「顶部导航区」「内容列表区」

  • 每个界面固定按「定位 → 布局结构 → 关键组件 → 交互与状态 → 跳转关系」五段描述。
  • 「布局结构」采用自上而下的分区罗列，等价于低保真线框，开发可据此还原页面骨架。

4. 用户端原型（12 模块 / 49 界面）

4.1 U1 账号与准入（U-01 ~ U-06）

模块职责：完成用户从启动、登录、注册、找回密码到首次资料补全与协议授权的完整准入链路。

模块边界：仅负责身份建立与合规授权；用户资料编辑归 U11，账号安全设置归 U11 设置页，本模块不承载业务功能入口。

U-01启动闪屏页

  • 界面定位：App / H5 冷启动的第一屏，承担品牌露出与登录态判定。
  • 布局结构：
    1. 全屏品牌区：深色渐变背景 + 品牌 Logo + 品牌语；
    2. 底部合规区：备案号、版权信息；
    3. 右下角「跳过」按钮（仅广告位存在时展示）。
  • 关键组件：Logo 图、渐变背景、版本号、跳过按钮、加载指示。
  • 交互与状态：
    • 启动后 1.5s 内完成登录态校验：已登录 → U-07 首页；未登录 → U-02 登录页；
    • 首次安装展示 3 屏引导（可跳过），非首次直接进入；
    • 加载态：Logo 下方细进度条，超过 3s 显示「网络较慢，请稍候」。
  • 跳转关系：→ U-02 登录页 / U-07 首页。

U-02登录页

  • 界面定位：手机号 + 验证码 / 密码双模式登录入口。
  • 布局结构：
    1. 品牌区：Logo + 欢迎语「夜深了，好梦开始的地方」；
    2. 表单区：手机号输入、验证码 / 密码输入、获取验证码按钮、登录主按钮；
    3. 切换区：「验证码登录 / 密码登录」切换；
    4. 辅助区：注册入口、忘记密码、第三方登录（微信）；
    5. 底部：协议勾选（默认未勾选）。
  • 关键组件：手机号输入框（11 位数字键盘）、验证码输入框（6 位分格）、倒计时按钮、主按钮、协议勾选框。
  • 交互与状态：
    • 手机号未满 11 位或未勾选协议时主按钮置灰；
    • 获取验证码后 60s 倒计时，倒计时内不可重复获取；
    • 校验失败：表单上方红色提示条，输入框标红；
    • 登录中：主按钮 Loading，禁止返回；
    • 连续 5 次密码错误：提示「账号已临时锁定，请 15 分钟后重试」。
  • 跳转关系：→ U-03 注册 / U-04 找回密码 / U-05 首次资料引导（新用户）/ U-07 首页（老用户）。

U-03注册页

  • 界面定位：新用户手机号注册，与首次资料补全分离，注册即建号。
  • 布局结构：
    1. 返回栏：返回 + 标题「注册」；
    2. 表单区：手机号、验证码、设置密码（含强度提示）、确认密码；
    3. 协议区：用户协议、隐私政策勾选；
    4. 底部：注册主按钮 + 「已有账号，去登录」。
  • 关键组件：手机号输入、验证码分格输入、密码输入（明文切换）、密码强度条（弱 / 中 / 强）、协议链接。
  • 交互与状态：
    • 密码规则：8~20 位，含字母与数字，实时校验并提示；
    • 两次密码不一致时确认框标红并提示；
    • 手机号已注册：提示「该手机号已注册，可直接登录」并提供跳转按钮；
    • 注册成功：Toast「注册成功」后进入 U-05。
  • 跳转关系：→ U-05 首次资料引导 / U-02 登录页。

U-04找回密码页

  • 界面定位：通过手机号验证码重置登录密码。
  • 布局结构：
    1. 返回栏；
    2. 步骤条（验证手机号 → 设置新密码）；

5.1 管理端通用框架

┌──────────────────────────────────────────────────────┐
│ 顶栏：面包屑 / 页面标题        搜索  消息  帮助  账号 │
├──────────┬───────────────────────────────────────────┤
│ 侧栏     │                                           │
│ 工作台   │              内容区                       │
│ 数据看板 │   （筛选条 / 统计卡 / 表格 / 图表 / 抽屉）  │
│ 用户中心 │                                           │
│ 内容中心 │                                           │
│ ……       │                                           │
└──────────┴───────────────────────────────────────────┘
  • 侧栏按一级菜单两级展开，当前菜单高亮紫色左边条；支持折叠为图标模式。
  • 顶栏面包屑随路由变化（如「内容中心 / 音频管理 / 编辑音频」）。
  • 列表页统一结构：筛选条（上）→ 批量操作区 → 数据表格 → 分页器（右下）。

模块边界：仅系统管理员可见；不涉及业务规则配置（业务规则归属各业务模块）。

A-54参数与字典配置页

  • 界面定位：集中管理全局参数、数据字典与基础配置。
  • 布局结构：
    1. 左侧分组：基础参数 / 业务参数 / 字典管理 / 支付配置 / 存储配置；
    2. 右侧内容区：
      • 基础参数：站点名称、Logo、客服电话、服务时间、备案号；
      • 业务参数：订单超时时间、预约取消规则、补卡次数上限、评价展示条数；
      • 字典管理：字典类型列表 + 字典项维护（键、值、排序、状态）；
    3. 底部：保存按钮。
  • 关键组件：分组导航、参数表单、字典表格、保存操作。
  • 交互与状态：
    • 参数修改需二次确认，并提示影响范围；
    • 关键参数（如订单超时）修改后仅对新订单生效；
    • 字典项被业务引用时不可删除；
    • 所有修改写入审计日志。
  • 跳转关系：→ A-55 操作日志。

A-55操作日志与审计页

  • 界面定位：追溯后台所有敏感操作，满足合规与追责要求。
  • 布局结构：
    1. 筛选：操作人、模块、操作类型、时间区间、结果（成功 / 失败）、IP；
    2. 统计条：今日操作数、失败数、敏感操作数；
    3. 表格列：时间、操作人、角色、模块、操作类型、对象、结果、IP、耗时、操作（查看详情）；
    4. 详情抽屉：请求摘要、变更前后对比（字段级）、来源 IP 与设备；
    5. 导出按钮。
  • 关键组件：筛选、统计条、表格、字段级对比、导出。
  • 交互与状态：
    • 日志只读，任何角色不可删除；
    • 敏感操作（导出用户数据、查看完整手机号、退款）单独标记红色；
    • 日志保留期限在页面注明，超期自动归档；
    • 支持按操作人下钻查看其全部操作轨迹。
  • 跳转关系：→ A-04 管理员账号。
