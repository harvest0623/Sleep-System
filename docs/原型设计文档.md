# 助眠服务管理系统 · 原型设计文档

> 版本：V1.0　|　日期：2026-11-24　|　适用范围：用户端（移动 H5）+ 管理后台（PC Web）
> 文档性质：交互与界面原型说明，不含代码、技术实现与数据库设计

---

## 1. 文档说明

### 1.1 编写目的

本文档在《功能模块划分与界面清单》基础上，对用户端 12 个模块 / 49 个界面、管理端 13 个模块 / 55 个界面的**页面结构、区块布局、组件构成、交互行为与状态规则**进行逐页定义，作为 UI 设计、前端开发、测试用例编写的唯一依据。

### 1.2 目标读者

| 角色 | 关注章节 |
| --- | --- |
| 产品 / 需求方 | 第 3 章信息架构、第 4~5 章逐页原型 |
| UI 设计师 | 第 2 章设计规范、第 4~5 章布局结构 |
| 前端开发 | 第 2 章规范、第 4~5 章组件与交互、第 6 章通用组件 |
| 测试 | 第 4~5 章交互与状态、第 7 章双端联动 |

### 1.3 术语与约定

| 术语 | 含义 |
| --- | --- |
| 界面编号 | U-xx 表示用户端界面，A-xx 表示管理端界面，全局唯一、不再复用 |
| 区块 | 页面内的一个视觉分区，如「顶部导航区」「内容列表区」 |
| 状态 | 界面在特定数据条件下的呈现，统一定义为：默认态、加载态、空态、错误态、无权限态 |
| 主操作 | 每个界面有且仅有一个视觉权重最高的按钮，全页不超过 1 个 |
| 抽屉 / 弹层 | 不离开当前页面的浮层容器，用于轻量编辑与确认 |

### 1.4 文档使用方式

- 每个界面固定按「定位 → 布局结构 → 关键组件 → 交互与状态 → 跳转关系」五段描述。
- 「布局结构」采用自上而下的分区罗列，等价于低保真线框，开发可据此还原页面骨架。
- 所有界面默认遵循第 2 章设计规范与第 6 章通用组件，页面描述中不再重复基础规范。

## 2. 设计规范

### 2.1 用户端（移动 H5）

| 项目 | 规范 |
| --- | --- |
| 设计基准 | 375 × 812（iPhone X 基准），最小兼容 320 宽 |
| 安全区 | 顶部状态栏 44px，底部 Home Indicator 34px，均需避让 |
| 栅格 | 4 列栅格，左右安全边距 16px，卡片间距 12px |
| 主色 | 深夜紫 `#6D4AFF`，用于主按钮、选中态、进度条 |
| 辅色 | 月光青 `#3DD6C4`（数据正向）、警示橙 `#FF8A3D`、危险红 `#FF4D4F` |
| 背景 | 页面底色 `#0E0B1F`（深色模式优先），卡片 `#1A1630`，分割线 `rgba(255,255,255,0.08)` |
| 字号 | 大标题 28 / 页面标题 20 / 卡片标题 17 / 正文 15 / 辅助 13 / 说明 11 |
| 圆角 | 卡片 20，按钮 24（胶囊），输入框 14，标签 8 |
| 触控目标 | 不小于 44 × 44，列表行高不小于 56 |
| 底部 Tab | 5 项：首页 / 记录 / 计划 / 消息 / 我的，高度 56 + 安全区 |
| 动效 | 页面转场 280ms 缓出，列表加载骨架屏，按钮点击缩放 0.97 |

### 2.2 管理端（PC Web）

| 项目 | 规范 |
| --- | --- |
| 设计基准 | 1440 × 900，最小支持 1280 宽 |
| 布局 | 左侧导航 220px（可收起为 64px）+ 顶栏 56px + 内容区自适应 |
| 主色 | 与用户端一致 `#6D4AFF`，侧栏深底 `#171429` |
| 字号 | 页面标题 20 / 卡片标题 16 / 正文 14 / 表格 13 / 辅助 12 |
| 表格 | 行高 48，表头吸顶，斑马纹关闭，悬浮高亮 `#F5F3FF` |
| 表单 | 标签右对齐宽 120px，控件宽 320，必填项前置红色星号 |
| 弹层 | 表单类用居中弹窗（宽 640 / 800），详情类用右侧抽屉（宽 560） |
| 反馈 | 操作成功 Toast 2s，删除/退款等不可逆操作二次确认 |

### 2.3 通用交互反馈

| 场景 | 规则 |
| --- | --- |
| 提交中 | 主按钮置灰 + 内嵌 Loading，禁止重复提交 |
| 表单校验 | 失焦即校验，错误信息置于控件下方，红色 12px |
| 列表加载 | 首屏骨架屏，翻页底部 Loading，无更多显示「已经到底了」 |
| 空态 | 插画 + 一句说明 + 一个引导按钮（如「去添加」） |
| 错误态 | 错误图标 + 原因 + 「重试」按钮 |
| 删除确认 | 明确写出对象名称，危险按钮在右 |
| 金额展示 | 统一 `¥` + 两位小数，负数前置 `-` |

## 4. 用户端原型（12 模块 / 49 界面）

### 4.1 U1 账号与准入（U-01 ~ U-06）

**模块职责**：完成用户从启动、登录、注册、找回密码到首次资料补全与协议授权的完整准入链路。

**模块边界**：仅负责身份建立与合规授权；用户资料编辑归 U11，账号安全设置归 U11 设置页，本模块不承载业务功能入口。

#### U-01 启动闪屏页

- **界面定位**：App / H5 冷启动的第一屏，承担品牌露出与登录态判定。
- **布局结构**：
  1. 全屏品牌区：深色渐变背景 + 品牌 Logo + 品牌语；
  2. 底部合规区：备案号、版权信息；
  3. 右下角「跳过」按钮（仅广告位存在时展示）。
- **关键组件**：Logo 图、渐变背景、版本号、跳过按钮、加载指示。
- **交互与状态**：
  - 启动后 1.5s 内完成登录态校验：已登录 → U-07 首页；未登录 → U-02 登录页；
  - 首次安装展示 3 屏引导（可跳过），非首次直接进入；
  - 加载态：Logo 下方细进度条，超过 3s 显示「网络较慢，请稍候」。
- **跳转关系**：→ U-02 登录页 / U-07 首页。

#### U-02 登录页

- **界面定位**：手机号 + 验证码 / 密码双模式登录入口。
- **布局结构**：
  1. 品牌区：Logo + 欢迎语「夜深了，好梦开始的地方」；
  2. 表单区：手机号输入、验证码 / 密码输入、获取验证码按钮、登录主按钮；
  3. 切换区：「验证码登录 / 密码登录」切换；
  4. 辅助区：注册入口、忘记密码、第三方登录（微信）；
  5. 底部：协议勾选（默认未勾选）。
- **关键组件**：手机号输入框（11 位数字键盘）、验证码输入框（6 位分格）、倒计时按钮、主按钮、协议勾选框。
- **交互与状态**：
  - 手机号未满 11 位或未勾选协议时主按钮置灰；
  - 获取验证码后 60s 倒计时，倒计时内不可重复获取；
  - 校验失败：表单上方红色提示条，输入框标红；
  - 登录中：主按钮 Loading，禁止返回；
  - 连续 5 次密码错误：提示「账号已临时锁定，请 15 分钟后重试」。
- **跳转关系**：→ U-03 注册 / U-04 找回密码 / U-05 首次资料引导（新用户）/ U-07 首页（老用户）。

#### U-03 注册页

- **界面定位**：新用户手机号注册，与首次资料补全分离，注册即建号。
- **布局结构**：
  1. 返回栏：返回 + 标题「注册」；
  2. 表单区：手机号、验证码、设置密码（含强度提示）、确认密码；
  3. 协议区：用户协议、隐私政策勾选；
  4. 底部：注册主按钮 + 「已有账号，去登录」。
- **关键组件**：手机号输入、验证码分格输入、密码输入（明文切换）、密码强度条（弱 / 中 / 强）、协议链接。
- **交互与状态**：
  - 密码规则：8~20 位，含字母与数字，实时校验并提示；
  - 两次密码不一致时确认框标红并提示；
  - 手机号已注册：提示「该手机号已注册，可直接登录」并提供跳转按钮；
  - 注册成功：Toast「注册成功」后进入 U-05。
- **跳转关系**：→ U-05 首次资料引导 / U-02 登录页。

#### U-04 找回密码页

- **界面定位**：通过手机号验证码重置登录密码。
- **布局结构**：
  1. 返回栏；
  2. 步骤条（验证手机号 → 设置新密码）；
  3. 步骤一表单：手机号 + 验证码；
  4. 步骤二表单：新密码 + 确认新密码；
  5. 底部主按钮（下一步 / 完成）。
- **关键组件**：步骤指示器、手机号输入、验证码输入、密码输入、强度条。
- **交互与状态**：
  - 步骤间可返回上一步，已填内容保留；
  - 手机号不存在：提示「该手机号未注册」，附「去注册」；
  - 重置成功：Toast 后自动跳转登录页，并预填手机号。
- **跳转关系**：→ U-02 登录页。

#### U-05 首次资料引导页

- **界面定位**：新用户 3 步轻量建档，为个性化推荐提供最小必要信息。
- **布局结构**：
  1. 进度指示：第 1/3 步；
  2. 步骤一「基础信息」：昵称、性别、年龄段、头像（可跳过）；
  3. 步骤二「睡眠状况」：入睡困难程度、平均入睡时长、常醒时段（多选）；
  4. 步骤三「助眠偏好」：偏好内容类型（白噪音 / 冥想 / 故事 / 音乐，多选）、期望提醒时间；
  5. 底部：上一步 / 下一步 / 跳过。
- **关键组件**：头像上传、单选胶囊组、多选标签组、时间选择器、进度点。
- **交互与状态**：
  - 每步均为非必填，可整体跳过；
  - 选择项即时高亮（紫色描边 + 浅紫底）；
  - 提交中展示 Loading，失败保留填写内容并提示重试。
- **跳转关系**：→ U-07 首页（完成后）。

#### U-06 隐私授权与协议页

- **界面定位**：集中展示并管理隐私政策、用户协议、个性化推荐与消息推送授权。
- **布局结构**：
  1. 返回栏；
  2. 协议列表：用户服务协议、隐私政策、儿童个人信息保护规则（点击查看全文）；
  3. 授权开关组：个性化推荐、消息推送、健康数据用于分析；
  4. 底部：同意并继续 / 暂不同意。
- **关键组件**：协议条目（右侧箭头）、开关组件、全文阅读页入口。
- **交互与状态**：
  - 关闭「个性化推荐」后首页推荐位切换为通用内容，页面提示生效；
  - 点击「暂不同意」二次确认，说明将影响的功能范围；
  - 协议更新后再次进入强制展示，需重新确认。
- **跳转关系**：→ U-07 首页 / 协议全文页。

### 4.2 U2 首页与发现（U-07 ~ U-11）

**模块职责**：聚合睡眠概览、今日计划、推荐内容与快捷服务入口，承担发现与分流。

**模块边界**：只做聚合展示与跳转，不承载记录编辑、播放控制、下单等具体业务操作。

#### U-07 首页

- **界面定位**：用户每日进入的主入口，一屏内回答「昨晚睡得怎样、今天做什么、现在听什么」。
- **布局结构**：
  1. 顶部问候区：时段问候语 + 日期 + 天气/心情图标 + 消息铃铛（未读红点）；
  2. 睡眠概览卡：昨晚睡眠时长、入睡时间、睡眠评分环形图、与上周对比；
  3. 今日计划卡：当前计划名称、今日任务、打卡按钮、进度环；
  4. 快捷入口区：4 宫格（睡眠测评 / 找助眠师 / 助眠商城 / 睡前社区）；
  5. 推荐内容区：横向滑动卡片（音频 / 文章混排），带「换一批」；
  6. 底部 Tab 栏。
- **关键组件**：评分环形图、数据对比标签（↑↓）、任务卡、宫格入口、横滑卡片列表、骨架屏。
- **交互与状态**：
  - 下拉刷新触发数据重载，顶部显示刷新动画；
  - 无睡眠数据：概览卡替换为「昨晚没有记录，去补录」引导卡；
  - 未加入计划：计划卡替换为「选一个适合你的助眠计划」推荐卡；
  - 卡片点击：概览卡 → U-12，计划卡 → U-24，内容卡 → U-17 / U-09。
- **跳转关系**：→ U-12 日报 / U-24 我的计划 / U-17 播放器 / U-09 文章详情 / U-30 助眠师 / U-35 商城 / U-44 社区 / U-41 消息中心。

#### U-08 睡眠知识列表页

- **界面定位**：以图文 / 短视频形式沉淀睡眠科普内容，支持分类浏览。
- **布局结构**：
  1. 顶部搜索框 + 返回；
  2. 分类标签栏（横向滚动）：全部 / 入睡技巧 / 睡眠科学 / 情绪调节 / 饮食运动；
  3. 内容列表：大图卡（首条）+ 左文右图列表项；
  4. 底部：加载更多。
- **关键组件**：搜索框、标签栏、文章卡片、阅读量 / 时长标签、下拉刷新。
- **交互与状态**：
  - 切换分类即时刷新列表并回到顶部；
  - 空态：「该分类暂无内容，看看其他分类」；
  - 分页到底提示「已经到底了」。
- **跳转关系**：→ U-09 文章详情 / U-10 搜索。

#### U-09 文章详情页

- **界面定位**：承载科普长文 / 短视频的阅读与互动。
- **布局结构**：
  1. 顶部悬浮返回 + 分享；
  2. 标题区：标题、作者、发布时间、阅读量；
  3. 正文区：图文混排，支持视频内嵌；
  4. 关联推荐区：「相关助眠音频」横向卡片；
  5. 底部操作栏：收藏、点赞、分享、相关商品 / 服务入口。
- **关键组件**：富文本容器、视频播放器、收藏按钮、底部悬浮操作栏、相关推荐卡。
- **交互与状态**：
  - 滚动时顶部栏由透明渐变为深色实底；
  - 收藏 / 点赞即时切换图标并 Toast 反馈；
  - 正文加载失败：显示「内容加载失败，点击重试」。
- **跳转关系**：→ U-17 播放器 / U-36 商品详情 / U-08 返回列表。

#### U-10 搜索页

- **界面定位**：全局搜索音频、文章、助眠师、商品。
- **布局结构**：
  1. 顶部搜索栏（自动聚焦）+ 取消；

#### U-11 内容分类页

- **跳转关系**：→ U-17 播放器 / U-18 混音器。

### 4.3 U3 睡眠记录与报告（U-12 ~ U-16）

**模块职责**：呈现睡眠数据、支持手动补录、提供多周期报告与趋势洞察。

**模块边界**：仅负责数据展示与补录；设备采集、算法评分的配置在管理端 A-11，用户端不可配置评分模型。

#### U-12 睡眠日报页

- **界面定位**：展示单晚睡眠的完整明细与评分解读。
- **布局结构**：
  1. 顶部日期切换（左右箭头 + 日期）；
  2. 评分区：睡眠评分大数字 + 环形进度 + 评级文案（优秀 / 良好 / 一般 / 偏差）；
  3. 核心指标区：入睡时间、起床时间、总时长、深睡 / 浅睡 / REM 占比（横向堆叠条）；
  4. 明细区：入睡耗时、夜醒次数、平均心率（若接入设备）；
  5. 建议区：2~3 条基于数据的助眠建议 + 「查看相关音频」；
  6. 底部：补录 / 编辑记录入口。
- **关键组件**：日期切换器、评分环、堆叠占比条、指标网格、建议卡。
- **交互与状态**：
  - 左右滑动切换日期，边界日期禁用箭头；
  - 无数据：展示「这一晚还没有记录」+ 补录按钮；
  - 数据不足（如仅手动补录）：对应指标显示「--」并注明原因。
- **跳转关系**：→ U-14 补录 / U-13 周报 / U-17 播放器。

#### U-13 睡眠周报页

- **界面定位**：以周为单位的趋势汇总与改善建议。
- **布局结构**：
  1. 顶部周期切换（本周 / 上周 / 自定义周）；
  2. 周概览卡：平均时长、平均评分、达标天数（如 5/7）；
  3. 柱状趋势图：7 天睡眠时长柱状 + 目标线；
  4. 结构分析：深睡占比周均值与环比；
  5. 规律性分析：入睡时间波动区间、作息规律度评分；
  6. 周建议卡：3 条可执行建议。
- **关键组件**：周期选择器、指标卡、柱状图、目标基准线、建议列表。
- **交互与状态**：
  - 点击柱状图某一天，浮层展示当日明细并可跳转日报；
  - 数据不足 3 天：图表区替换为「数据太少，继续记录 3 天即可生成周报」。
- **跳转关系**：→ U-12 日报 / U-15 趋势分析。

#### U-14 睡眠记录补录页

- **界面定位**：手动录入或修正某一晚的睡眠数据。
- **布局结构**：
  1. 顶部返回 + 标题「补录睡眠」；
  2. 日期选择：默认昨晚，可回选近 30 天；
  3. 时间区：上床时间、入睡时间、起床时间（滚轮选择器）；
  4. 主观感受区：入睡难度（1~5 星）、夜醒次数（步进器）、起床状态（单选）；
  5. 备注区：文本输入（限 100 字）；
  6. 底部：保存按钮。
- **关键组件**：日期选择器、时间滚轮、星级评分、步进器、单选组、多行输入。
- **交互与状态**：
  - 起床时间早于上床时间时提示「时间不合理，请检查」并阻止保存；
  - 已有记录时进入为编辑态，标题变为「编辑睡眠记录」，预填原数据；
  - 保存成功 Toast 后返回来源页并刷新数据。
- **跳转关系**：→ U-12 日报（返回并刷新）。

#### U-15 睡眠趋势分析页

- **界面定位**：以 7 天 / 30 天 / 90 天维度观察睡眠指标变化。
- **布局结构**：
  1. 顶部维度切换（周 / 月 / 季）；
  2. 指标选择 Tab：时长 / 评分 / 入睡时间 / 夜醒次数；
  3. 折线趋势图（支持手指拖动查看数值气泡）；
  4. 对比卡：本期均值 vs 上期均值，标注变化幅度；
  5. 洞察卡：系统生成的 2 条趋势结论（如「入睡时间整体推迟 32 分钟」）。
- **关键组件**：维度切换、指标 Tab、折线图、数值气泡、对比卡。
- **交互与状态**：
  - 切换指标时图表带过渡动画；
  - 数据点少于 3 个时提示样本不足；
  - 图表支持双指缩放时间轴（可选）。
- **跳转关系**：→ U-12 日报 / U-13 周报。

#### U-16 睡眠日历页

- **界面定位**：月历形式回顾每日睡眠，快速定位异常日。
- **布局结构**：
  1. 顶部月份切换；
  2. 月历网格：每日格子用色块深浅表示评分，下方小圆点表示是否有记录；
  3. 图例：优秀 / 良好 / 一般 / 偏差 / 无记录；
  4. 月度统计条：记录天数、平均时长、最佳 / 最差日期；
  5. 底部：选中日期的简要卡片（点击格子后展示，可跳日报）。
- **关键组件**：月历组件、色阶图例、统计条、日期详情浮卡。
- **交互与状态**：
  - 点击有记录日期弹出浮卡；点击无记录日期弹出「补录」按钮；
  - 左右滑动切换月份；
  - 无任何记录：日历全灰 + 中央引导补录。
- **跳转关系**：→ U-12 日报 / U-14 补录。

### 4.4 U4 助眠内容与播放（U-17 ~ U-21）

**模块职责**：提供音频播放、白噪音混音、定时关闭、收藏列表与课程播放能力。

**模块边界**：只负责「听」与「播放控制」；内容生产与上架在管理端 A4，购买与付费解锁在 U8。

#### U-17 音频播放器页

- **界面定位**：全屏沉浸式播放器，是助眠内容消费的核心界面。
- **布局结构**：
  1. 顶部栏：收起（下拉箭头）、标题、更多（分享 / 举报）；
  2. 封面区：大尺寸封面 + 缓动呼吸动画，随播放状态起伏；
  3. 信息区：音频标题、作者 / 来源、当前分类标签；
  4. 进度区：进度条（可拖动）+ 当前时间 / 总时长；
  5. 控制区：上一首、播放 / 暂停（大按钮）、下一首、循环模式；
  6. 功能条：定时关闭、收藏、倍速、音量；
  7. 底部：相关推荐（上滑展开清单）。
- **关键组件**：封面呼吸动画、可拖动进度条、主播放按钮、定时器入口、收藏按钮、倍速面板。
- **交互与状态**：
  - 播放中息屏后继续播放（需权限），锁屏控制支持暂停 / 下一首；
  - 缓冲中：播放按钮变为环形 Loading，显示「缓冲中」；
  - 播放失败：Toast「播放失败，请检查网络」并自动尝试下一首；
  - 支持后台播放与耳机线控；
  - 上滑推荐区：点击替换当前播放，不新开页面。
- **跳转关系**：→ U-19 定时关闭 / U-21 课程详情 / U-18 混音器。

#### U-18 白噪音混音器页

- **界面定位**：多个自然声 / 白噪音叠加播放，自定义专属助眠声场。
- **布局结构**：
  1. 顶部返回 + 标题「声音混合」+ 保存；
  2. 声场画布区：以圆环或声波图形展示当前混合状态；
  3. 音轨列表：每条音轨含图标、名称、开关、音量滑杆（雨声 / 海浪 / 风声 / 篝火 / 虫鸣 / 钢琴等）；
  4. 预设区：官方预设（深度睡眠 / 专注 / 冥想）+ 我的预设；
  5. 底部：播放 / 暂停主按钮 + 定时关闭入口。
- **关键组件**：音轨开关、音量滑杆、声场可视化、预设卡片、保存弹窗。
- **交互与状态**：
  - 同时最多 5 条音轨，超出提示「最多混合 5 种声音」；
  - 调节音量实时生效，无延迟；
  - 保存预设需输入名称，重名时提示覆盖；
  - 无网络时仅可播放已缓存音轨。
- **跳转关系**：→ U-19 定时关闭 / U-17 播放器。

#### U-19 定时关闭页

- **界面定位**：设置播放自动停止时间，避免整夜播放耗电与干扰。
- **布局结构**：
  1. 底部弹层（半屏）；
  2. 快捷选项：15 分钟 / 30 分钟 / 45 分钟 / 60 分钟 / 90 分钟；
  3. 自定义：时长滚轮或「播放完当前音频后停止」；
  4. 底部：取消 / 确定。
- **关键组件**：时长胶囊组、自定义滚轮、单选状态、确认按钮。
- **交互与状态**：
  - 已设定时：弹层顶部显示「将在 23:45 停止播放」，并提供「取消定时」；
  - 选择「播完当前」时展示当前剩余时长；
  - 确认后 Toast「已设置 30 分钟后关闭」。
- **跳转关系**：返回来源播放器 / 混音器。

#### U-20 我的收藏与播放列表页

- **界面定位**：集中管理收藏内容、自建歌单与最近播放。
- **布局结构**：
  1. 顶部返回 + 标题 + 编辑按钮；
  2. 分组 Tab：收藏音频 / 自建歌单 / 最近播放；
  3. 列表区：音频行（封面、标题、时长、更多操作）；
  4. 歌单卡片：封面拼图 + 名称 + 数量；
  5. 底部：新建歌单（悬浮按钮）。
- **关键组件**：Tab 切换、音频行、滑动操作（取消收藏 / 删除）、歌单卡片、新建歌单弹窗。
- **交互与状态**：
  - 左滑出现「取消收藏」红色操作；
  - 编辑态支持批量选择与批量移除；
  - 空态：「还没有收藏，去声音库逛逛」+ 跳转按钮；
  - 最近播放保留最近 50 条，超出自动清理。
- **跳转关系**：→ U-17 播放器 / U-11 内容分类。

#### U-21 课程 / 冥想详情页

- **界面定位**：系列课程或多集冥想内容的分集播放与进度追踪。
- **布局结构**：
  1. 顶部：返回 + 分享；
  2. 课程头图区：大图 + 课程标题 + 讲师 + 集数 / 总时长 + 学习人数；
  3. 简介区：课程介绍（折叠展开）；
  4. 章节列表：第 1 集、第 2 集……含时长、已学标记、锁标（付费课）；
  5. 底部固定栏：开始学习 / 继续学习 + 收藏。
- **关键组件**：课程头图、折叠文本、章节行、锁标、底部固定 CTA。
- **交互与状态**：
  - 未解锁集数点击弹出会员 / 购买引导（跳 U-40 / U-36）；
  - 已学完章节显示对勾，整体进度以环形显示在头图角标；
  - 断点续播：进入时定位到最后学习集数。
- **跳转关系**：→ U-17 播放器 / U-40 会员中心 / U-36 商品详情。

### 4.5 U5 助眠计划与打卡（U-22 ~ U-25）

- **关键组件**：轮播横幅、筛选胶囊、计划卡片、进度标签。

- **关键组件**：头图、信息标签、日程时间轴、评价卡片、底部固定 CTA。
- **交互与状态**：

  - 已加入则按钮变为「继续计划」，点击直达 U-24；
  - 计划已下架：隐藏加入按钮并提示「该计划已结束」。
- **跳转关系**：→ U-24 我的计划 / U-17 播放器。

#### U-24 我的计划与今日打卡页

- **界面定位**：计划执行主界面，完成当天任务并打卡。
- **布局结构**：
  1. 顶部：返回 + 计划名称 + 更多（退出计划）；

  5. 打卡日历：本月打卡点阵；

- **关键组件**：进度环、任务勾选行、打卡主按钮、日历点阵、徽章。
- **交互与状态**：
  - 打卡成功：按钮变为「今日已打卡」，播放简短庆祝动效；
  - 补卡：每期最多 2 次补卡机会，超过提示不可补；
  - 断卡：连续中断后提示「连续记录已重置」，但总进度保留；
  - 任务跳转：听音频任务点击直达 U-17。
- **跳转关系**：→ U-17 播放器 / U-25 打卡日历 / U-22 计划广场。

#### U-25 打卡日历与成就页

- **关键组件**：月历、统计卡、徽章网格、成就详情弹层。

### 4.6 U6 睡眠测评（U-26 ~ U-29）

**模块职责**：提供标准化睡眠自评量表，完成答题、生成结果解读并留存历史。

## 5. 管理端原型（13 模块 / 55 界面）

### 5.1 管理端通用框架

除登录类页面外，所有管理端界面共用同一外层框架，后续各界面只描述**内容区**：

```
┌──────────────────────────────────────────────────────┐
│ 顶栏：面包屑 / 页面标题        搜索  消息  帮助  账号 │
├──────────┬───────────────────────────────────────────┤
│ 侧栏     │                                           │
│ 工作台   │              内容区                       │
│ 数据看板 │   （筛选条 / 统计卡 / 表格 / 图表 / 抽屉）  │
│ 用户中心 │                                           │
│ 内容中心 │                                           │
│ ……       │                                           │
└──────────┴───────────────────────────────────────────┘
```

- 侧栏按一级菜单两级展开，当前菜单高亮紫色左边条；支持折叠为图标模式。
- 顶栏面包屑随路由变化（如「内容中心 / 音频管理 / 编辑音频」）。
- 列表页统一结构：筛选条（上）→ 批量操作区 → 数据表格 → 分页器（右下）。
- 详情页统一结构：页头（标题 + 状态标签 + 操作按钮）→ 信息卡片分组 → 关联 Tab。

### 5.2 A1 登录与权限（A-01 ~ A-05）

**模块职责**：管理员身份认证、工作台聚合、账号与角色权限的配置管理。

**模块边界**：仅管理系统内部账号与菜单 / 数据权限；C 端用户账号归 A3。

#### A-01 管理端登录页

- **界面定位**：后台唯一入口，校验管理员身份。
- **布局结构**：
  1. 左侧品牌区：品牌图形 + 系统名称 + 一句产品定位（占 55% 宽）；
  2. 右侧登录卡：账号、密码、图形验证码、记住账号、登录按钮；
  3. 底部：版本号、备案信息。
- **关键组件**：输入框、验证码图片（点击刷新）、密码显隐、登录按钮、错误提示条。
- **交互与状态**：
  - 未填写完整时登录按钮置灰；
  - 连续 5 次失败锁定账号 15 分钟并提示联系管理员；
  - 登录成功按角色权限跳转默认首页（一般为 A-03 工作台）；
  - 首次登录强制修改初始密码。
- **跳转关系**：→ A-03 工作台 / A-02 找回密码。

#### A-02 找回 / 重置密码页

- **界面定位**：管理员自助重置后台密码。
- **布局结构**：
  1. 返回登录；
  2. 步骤条（验证身份 → 重置密码）；
  3. 表单：登录账号 + 绑定手机号验证码；新密码 + 确认密码；
  4. 提交按钮。
- **关键组件**：步骤条、账号输入、验证码倒计时、密码强度提示。
- **交互与状态**：
  - 账号与手机号不匹配时统一提示「信息校验失败」；
  - 重置成功后跳转登录页并预填账号。
- **跳转关系**：→ A-01 登录页。

#### A-03 工作台首页

- **界面定位**：管理员登录后的默认页，聚合待办与核心指标。
- **布局结构**：
  1. 欢迎区：问候语 + 角色名 + 今日日期；
  2. 核心指标卡（4 个）：今日新增用户、今日订单额、待处理预约、待审核内容；
  3. 待办列表：待审核内容 / 待处理退款 / 待回复咨询 / 待处理举报，均可点击跳转；
  4. 趋势图：近 7 天新增用户与订单额双轴折线；
  5. 快捷入口：常用功能宫格（按角色权限动态展示）；
  6. 系统公告区。
- **关键组件**：指标卡（含环比箭头）、待办列表、双轴折线图、快捷宫格。
- **交互与状态**：
  - 指标卡点击进入对应看板或列表；
  - 无待办时显示「暂无待处理事项」；
  - 数据权限受限的模块不展示对应卡片。
- **跳转关系**：→ A-06 运营总览 / A-18 审核队列 / A-41 退款售后 / A-32 预约列表。

#### A-04 管理员账号管理页

- **界面定位**：维护后台操作账号。
- **布局结构**：
  1. 筛选条：账号 / 姓名 / 角色 / 状态；
  2. 操作区：新增管理员、批量启用 / 禁用；
  3. 表格列：账号、姓名、手机号、角色、所属部门、状态、最后登录时间、操作；
  4. 分页器；
  5. 新增 / 编辑抽屉。
- **关键组件**：筛选表单、数据表格、状态开关、抽屉表单（账号、姓名、手机、角色、部门、初始密码）。
- **交互与状态**：
  - 账号唯一，重复时即时校验提示；
  - 禁用需二次确认，禁用后该账号立即失效；
  - 不可删除当前登录账号本人；
  - 初始密码创建后仅展示一次，提供复制按钮。
- **跳转关系**：→ A-05 角色权限。

#### A-05 角色与权限配置页

- **界面定位**：以角色为单位配置菜单权限与数据范围。
- **布局结构**：
  1. 左侧角色列表（可新增 / 重命名）；
  2. 右侧权限配置区：菜单权限树（勾选控制可见菜单与按钮）、数据范围（全部 / 本部门 / 仅本人）、特殊按钮权限；
  3. 底部：保存按钮；
  4. 角色成员 Tab：展示该角色下管理员并可增减。
- **关键组件**：角色列表、权限树（父子联动）、数据范围单选、成员表格。
- **交互与状态**：
  - 勾选父节点自动全选子节点，半选态以横线表示；
  - 系统内置「超级管理员」不可编辑与删除；
  - 保存后提示「权限将在成员下次刷新后生效」；
  - 删除角色前校验是否存在成员，存在则阻止。
- **跳转关系**：→ A-04 管理员账号。

### 5.3 A2 数据看板（A-06 ~ A-08）

**模块职责**：面向运营与管理层，提供业务整体、用户睡眠与交易三类数据看板。

**模块边界**：只做统计展示与导出；明细处理跳转对应业务列表，不在看板内做编辑。

#### A-06 运营总览看板

- **界面定位**：全局经营健康度的一屏概览。
- **布局结构**：
  1. 时间筛选：今日 / 近 7 天 / 近 30 天 / 自定义区间；
  2. 指标卡组（6 个）：新增用户、活跃用户、付费用户、订单量、交易额、客单价（各含环比）；
  3. 折线区：新增用户与活跃用户双线趋势；
  4. 环形图区：用户来源渠道占比；
  5. 排行区：热销商品 Top5、热门音频 Top5；
  6. 导出按钮（右上）。
- **关键组件**：时间筛选器、指标卡、折线图、环形图、排行榜列表、导出。
- **交互与状态**：
  - 切换时间区间全部图表联动刷新；
  - 数据加载中图表显示骨架占位；
  - 无数据区间图表显示「该时段暂无数据」；
  - 导出生成异步任务，完成后提示下载。
- **跳转关系**：→ A-07 用户看板 / A-08 交易看板 / 各明细列表。

#### A-07 用户与睡眠数据看板

- **界面定位**：观察用户规模、留存与睡眠质量整体分布。
- **布局结构**：
  1. 时间筛选；
  2. 用户指标：新增、活跃、留存率（次日 / 7 日 / 30 日）、会员转化率；
  3. 留存曲线图；
  4. 睡眠数据区：平均睡眠时长分布（直方图）、评分分布、平均入睡时间分布；
  5. 计划与测评区：计划参与人数、打卡完成率、测评完成率；
  6. 明细表：按日期的指标表 + 导出。
- **关键组件**：留存曲线、直方图、分布图、明细表格、导出。
- **交互与状态**：
  - 图表均可悬停查看具体数值；
  - 睡眠数据仅展示聚合结果，不呈现个人明细；
  - 无数据时占位说明。
- **跳转关系**：→ A-09 用户列表 / A-22 打卡记录 / A-26 测评记录。

#### A-08 交易看板

- **界面定位**：监控收入结构、退款与转化漏斗。
- **布局结构**：
  1. 时间筛选 + 业务类型筛选（商品 / 会员 / 咨询）；
  2. 收入指标：交易额、退款额、净收入、退款率、支付转化率；
  3. 趋势图：交易额与退款额双线；

- **关键组件**：筛选器、指标卡、双线图、堆叠柱、漏斗图、排行表。
- **交互与状态**：
  - 业务类型筛选影响全部区块；
  - 漏斗各层悬停显示转化率与绝对值；
  - 数据延迟时右上角标注「数据更新至 xx:xx」。
- **跳转关系**：→ A-39 订单列表 / A-42 对账流水 / A-43 会员方案。

#### A-18 内容审核队列页

  - 对账单导出为 Excel 并记录导出日志。
- **跳转关系**：→ A-39 订单列表 / A-35 预约退款 / A-29 助眠师结算 Tab。

### 5.11 A10 营销与会员（A-43 ~ A-47）

**模块职责**：配置会员体系、优惠券、营销活动与推送人群，评估营销效果。

**模块边界**：用户侧购买与领券在 U8；本模块只做规则配置与效果分析。

#### A-43 会员方案管理页

- **界面定位**：配置会员等级、价格方案与权益。
- **布局结构**：
  1. 方案卡片区：月卡 / 季卡 / 年卡（价格、有效期、销量、状态），支持新建方案；
  2. 权益配置区：勾选权益项（折扣率、专属内容、咨询券数量、免运费、积分倍率），每项可设参数；
  3. 等级体系 Tab：等级名称、升级条件、对应权益；
  4. 会员数据卡：会员总数、今日新增、续费率、到期提醒人数。
- **关键组件**：方案卡片、权益勾选与参数、等级表格、数据卡。
- **交互与状态**：
  - 修改价格仅影响新购，不改变已购会员有效期；
  - 权益变更保存后对全体会员即时生效，需二次确认；
  - 停用方案后用户端不再展示，历史会员不受影响；
  - 到期前 7 天自动触发续费提醒（走 A-49）。
- **跳转关系**：→ A-46 人群包 / A-08 交易看板。

#### A-44 优惠券管理页

- **界面定位**：创建与发放满减、折扣、新人券等优惠券。
- **布局结构**：
  1. 筛选条：券名、类型、状态、有效期；
  2. 操作区：新建优惠券；
  3. 表格列：券名、类型、面额 / 折扣、使用门槛、发放量、领取量、使用率、状态、操作；
  4. 新建 / 编辑弹层：券类型、面额、门槛、适用范围（全场 / 指定分类 / 指定商品）、有效期、发放方式（手动 / 领取中心 / 新人自动）、总量与限领。
- **关键组件**：筛选、表格、券配置表单、适用范围选择器、发放记录。
- **交互与状态**：
  - 面额不得高于门槛金额，校验拦截；
  - 已发放的券不可修改面额与门槛，只能停用；
  - 停用后未使用的券失效，需提示影响数量；
  - 发放记录可查看领取用户与使用状态。
- **跳转关系**：→ A-46 人群包 / A-47 营销效果。

#### A-45 活动与限时营销页

- **界面定位**：配置秒杀、满减、组合套餐等营销活动。
- **布局结构**：
  1. 活动列表：活动名、类型、时间、参与商品数、状态、操作；
  2. 新建活动抽屉：活动类型（限时折扣 / 秒杀 / 满减 / 套餐）、活动时间、适用商品、优惠规则、限购、是否叠加优惠券；
  3. 预览区：用户端活动样式预览；
  4. 数据区：活动期间 GMV、转化率、动销商品数。
- **关键组件**：活动列表、规则编辑器、商品选择器、预览、数据卡。
- **交互与状态**：
  - 活动时间重叠且商品冲突时提示；
  - 秒杀需设置库存与每人限购；
  - 活动开始后不可修改规则，仅可提前结束；
  - 结束后自动生成效果数据。
- **跳转关系**：→ A-37 商品列表 / A-47 营销效果。

#### A-46 推送人群包页

- **界面定位**：基于标签与行为圈选人群，供推送与发券使用。
- **布局结构**：
  1. 人群包列表：名称、来源（规则 / 导入 / 标签）、人数、更新时间、创建人、操作；
  2. 新建人群包：条件组合器（用户属性、行为、消费、睡眠数据），支持且 / 或嵌套；
  3. 实时预估：右侧展示预估人数与人群画像（性别、年龄段、会员占比）；
  4. 操作：保存、导出、去推送。
- **关键组件**：人群包表格、条件组合器、预估人数、画像图、推送入口。
- **交互与状态**：
  - 预估人数为 0 时提示调整条件；
  - 保存后人群包为快照，需手动刷新才会更新；
  - 含敏感健康数据的人群包仅授权角色可见；
  - 「去推送」携带人群包跳转 A-49。
- **跳转关系**：→ A-49 推送任务 / A-44 优惠券。

#### A-47 营销效果分析页

- **界面定位**：评估券、活动、推送的投入产出。
- **布局结构**：
  1. 筛选：营销类型、具体活动 / 券、时间区间；
  2. 指标卡：核销率、带动 GMV、客单价提升、ROI；
  3. 趋势图：核销与 GMV 双线；
  4. 对比表：活动前后关键指标对比；
  5. 明细表：按券 / 活动维度的效果排行。
- **关键组件**：筛选、指标卡、双线图、对比表、排行表、导出。
- **交互与状态**：
  - ROI 计算口径在页面提供说明气泡；
  - 无数据时提示「该活动尚未产生数据」；
  - 支持导出分析报告。
- **跳转关系**：→ A-44 优惠券 / A-45 活动 / A-49 推送任务。

### 5.12 A11 消息与推送（A-48 ~ A-50）

**模块职责**：配置消息模板、执行推送任务与站内公告。

**模块边界**：用户侧接收与提醒设置归 U9；本模块负责触达的配置与执行。

#### A-48 消息模板管理页

- **界面定位**：维护短信、推送、站内信的标准化模板。
- **布局结构**：
  1. 筛选条：模板名、渠道（推送 / 短信 / 站内信）、业务场景、状态；
  2. 操作区：新建模板；
  3. 表格列：模板名、渠道、场景、内容摘要、变量数、状态、更新时间、操作；
  4. 编辑弹层：模板名、渠道、适用场景、标题、正文（支持变量插入）、变量说明、测试发送。
- **关键组件**：筛选、表格、模板编辑器、变量插入器、测试发送、预览。
- **交互与状态**：
  - 正文长度按渠道校验（短信 70 字计费提示）；
  - 必填变量未插入时保存拦截；
  - 测试发送需填写接收手机号 / 账号，发送结果即时反馈；

- **跳转关系**：→ A-49 推送任务。

#### A-49 推送任务管理页

- **界面定位**：创建并执行面向人群的消息推送任务。
- **布局结构**：
  1. 筛选条：任务名、渠道、状态（草稿 / 待发送 / 发送中 / 已完成）；
  2. 操作区：新建推送；
  3. 表格列：任务名、渠道、目标人群、计划发送时间、发送量、送达率、点击率、状态、操作；
  4. 新建任务抽屉：任务名 → 选择人群包（来自 A-46）→ 选择模板 → 设置发送时间（立即 / 定时）→ 频控校验 → 预览；
  5. 详情抽屉：发送进度、成功 / 失败数、失败原因。
- **关键组件**：筛选、表格、多步抽屉、人群包选择器、模板选择器、频控提示。
- **交互与状态**：
  - 发送前展示「预计触达 X 人，本日该人群已触达 Y 次」；
  - 超出频控上限时阻止并提示；
  - 发送中不可编辑，仅可终止；
  - 定时任务可取消；
  - 任务保存为草稿不消耗额度。
- **跳转关系**：→ A-46 人群包 / A-48 模板 / A-47 效果分析。

#### A-50 站内信与公告管理页

- **界面定位**：发布全站公告、弹窗与站内信。
- **布局结构**：
  1. 筛选条：标题、类型（公告 / 弹窗 / 站内信）、状态、发布时间；
  2. 表格列：标题、类型、展示位置、目标人群、开始 / 结束时间、状态、操作；
  3. 新建弹层：类型、标题、内容（富文本）、跳转链接、展示位置（首页顶部 / 消息中心 / 启动弹窗）、目标人群、生效时间、优先级。
- **关键组件**：筛选、表格、富文本编辑、位置选择、时间范围、优先级排序。
- **交互与状态**：
  - 同位置多条公告按优先级展示，同优先级按时间倒序；
  - 定时生效的公告到点自动上下线；
  - 删除已生效公告会导致用户端立即消失，需二次确认；
  - 支持查看曝光量与点击量。
- **跳转关系**：→ 用户端 U-41 / U-42。

### 5.13 A12 社区运营（A-51 ~ A-53）

**模块职责**：审核社区动态与评论，处理举报与违规用户。

**模块边界**：用户发布与互动在 U10；本模块为可选模块，未开通时整个一级菜单隐藏。

#### A-51 社区动态审核页

- **界面定位**：审核用户发布的图文动态，处置违规内容。
- **布局结构**：
  1. 顶部 Tab：待审核 / 已通过 / 已屏蔽；
  2. 筛选：话题、发布时间、风险等级；
  3. 动态卡片流（双列或三列网格）：作者、正文摘要、图片、话题、风险标签；
  4. 点击卡片打开审核抽屉：完整内容、作者历史违规次数、机器检测结果、操作（通过 / 屏蔽 / 禁言作者）。
- **关键组件**：Tab、卡片网格、审核抽屉、风险标签、批量操作。
- **交互与状态**：
  - 支持多选批量通过 / 屏蔽；
  - 屏蔽必填原因并通知作者；
  - 同一作者 3 次违规自动触发禁言建议；
  - 审核后自动加载下一批。
- **跳转关系**：→ A-52 评论管理 / A-53 举报处理 / A-10 用户详情。

#### A-52 评论管理页

- **界面定位**：检索与处置动态下的评论与回复。
- **布局结构**：
  1. 筛选：关键词、作者、所属动态、时间区间、状态；
  2. 表格列：评论内容、作者、所属动态、点赞数、时间、状态、操作（屏蔽 / 删除 / 禁言）；
  3. 详情抽屉：评论上下文（所属动态与前后评论）、作者信息。
- **关键组件**：筛选、表格、上下文抽屉、批量屏蔽。
- **交互与状态**：
  - 关键词命中敏感词自动标红；
  - 删除仅限违规内容，需填原因；
  - 屏蔽后用户端显示「该评论已被屏蔽」；
  - 批量操作需确认影响条数。
- **跳转关系**：→ A-51 动态审核 / A-10 用户详情。

#### A-53 举报处理页

- **界面定位**：处理用户对动态、评论、助眠师或商品的举报。
- **布局结构**：
  1. 顶部 Tab：待处理 / 已处理 / 已驳回；
  2. 举报列表：举报对象类型、对象摘要、举报理由、举报人、时间、剩余时限；
  3. 处理抽屉：被举报内容详情、历史举报次数、处理动作（警告 / 删除内容 / 禁言 / 封禁 / 驳回举报）、处理说明；
  4. 底部：提交处理。
- **关键组件**：Tab、举报列表、对象预览、处置动作选择、说明输入。
- **交互与状态**：
  - 同一对象的多次举报自动聚合展示；
  - 处理结果通知举报人与被举报人；
  - 24 小时内未处理标红提醒；
  - 处置动作会联动 A-13 账号状态。
- **跳转关系**：→ A-13 黑名单 / A-51 动态审核 / A-52 评论管理。

### 5.14 A13 系统设置（A-54 ~ A-55）

**模块职责**：维护系统级参数、字典与审计日志。

**模块边界**：仅系统管理员可见；不涉及业务规则配置（业务规则归属各业务模块）。

#### A-54 参数与字典配置页

- **界面定位**：集中管理全局参数、数据字典与基础配置。
- **布局结构**：
  1. 左侧分组：基础参数 / 业务参数 / 字典管理 / 支付配置 / 存储配置；
  2. 右侧内容区：
     - 基础参数：站点名称、Logo、客服电话、服务时间、备案号；
     - 业务参数：订单超时时间、预约取消规则、补卡次数上限、评价展示条数；
     - 字典管理：字典类型列表 + 字典项维护（键、值、排序、状态）；
  3. 底部：保存按钮。
- **关键组件**：分组导航、参数表单、字典表格、保存操作。
- **交互与状态**：
  - 参数修改需二次确认，并提示影响范围；
  - 关键参数（如订单超时）修改后仅对新订单生效；
  - 字典项被业务引用时不可删除；
  - 所有修改写入审计日志。
- **跳转关系**：→ A-55 操作日志。

#### A-55 操作日志与审计页

- **界面定位**：追溯后台所有敏感操作，满足合规与追责要求。

  2. 统计条：今日操作数、失败数、敏感操作数；
  3. 表格列：时间、操作人、角色、模块、操作类型、对象、结果、IP、耗时、操作（查看详情）；
  4. 详情抽屉：请求摘要、变更前后对比（字段级）、来源 IP 与设备；
  5. 导出按钮。
- **关键组件**：筛选、统计条、表格、字段级对比、导出。
- **交互与状态**：
  - 日志只读，任何角色不可删除；
  - 敏感操作（导出用户数据、查看完整手机号、退款）单独标记红色；
  - 日志保留期限在页面注明，超期自动归档；
  - 支持按操作人下钻查看其全部操作轨迹。
- **跳转关系**：→ A-04 管理员账号。

### 6.1 用户端通用组件

| 组件 | 使用位置 | 规范要点 |

| 底部 Tab 栏 | 全局 | 5 项固定，当前项紫色图标 + 文字，未读用红点（不显示数字，超过 99 显示 99+） |

| 骨架屏 | 全部列表 / 详情 | 与真实布局同构，灰阶脉冲动画 |

### 6.2 管理端通用组件

| 组件 | 使用位置 | 规范要点 |
| --- | --- | --- |

| 分页器 | 全部列表页 | 右下角，显示总数，支持每页 20 / 50 / 100 |

| 抽屉 | 轻量编辑 / 详情 | 右侧滑出宽 560，支持层叠（最多 2 层） |

| 图表容器 | 看板 | 统一内边距 24，标题左 + 时间筛选右，无数据时居中占位 |
| 金额展示 | 交易相关 | 千分位 + 两位小数，正负着色，退款 / 支出前置负号 |

### 6.3 状态矩阵（全部界面通用）

| 状态 | 触发条件 | 呈现方式 |
| --- | --- | --- |
| 加载态 | 首次进入 / 切换筛选 | 骨架屏或局部 Loading，禁止空白页 |
| 空态 | 结果为 0 | 插画 + 说明 + 引导按钮 |
| 错误态 | 请求失败 | 错误提示 + 重试按钮，保留页面框架 |

| 离线态 | 网络断开 | 顶部通栏提示「网络已断开」，恢复后自动重连 |
| 登录失效 | Token 过期 | 全局拦截，跳转登录并保留来源页 |
